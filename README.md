# TradingSystem POC Drive Reader — OAuth information

This is a **public documentation-only** repository for the personal Desktop OAuth integration of TradingSystem. The actual TradingSystem code and operational data remain in a separate private repository.

## Public documents

- [Application home page](./index.html)
- [Privacy policy](./privacy.html)
- [Terms of use](./terms.html)

This repository contains no Google OAuth secrets, refresh tokens, account records, trading data, or application runtime code.

## Hosting

To host the site with GitHub Pages for free, choose **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**, then save.

When Pages has been published, the planned URLs are:

- Home: https://moyashimisosoup.github.io/trading-system-oauth-info/
- Privacy: https://moyashimisosoup.github.io/trading-system-oauth-info/privacy.html
- Terms: https://moyashimisosoup.github.io/trading-system-oauth-info/terms.html

**Important:** The host URL alone does not establish Google Search Console domain ownership. Google OAuth production and verification requirements must be checked separately. Do not change the current OAuth client, grant scopes, or credentials solely because these pages are available.
